# Oxygen Privacy Direction

Oxygen is designed around data minimization.

The standard build should contain no advertising SDK, behavioral analytics, marketing attribution, cross-app tracking, or mandatory account system.

Location permission is optional. A user must be able to search for and save locations manually.

Direct weather-provider requests can disclose the device IP address and requested coordinates to the selected provider. Provider-specific privacy implications must be documented in the Data Sources screen and provider documentation.
